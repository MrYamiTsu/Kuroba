Active & Upcoming Milestones
v1.0.7 Phase 7: Object-Oriented Programming & Language Ergonomics In Progress
▾
  • ✓Runtime type checking operator is (primitives, Nullable, Typed Collections, Tables, and Classes)
  • ✓Multi-variable declarations with trailing propagation (ivar a, b = 1, 2;, ivar c, d = 4;)
  • ✓Default parameter values in functions (function f(ivar a, ivar b = 1))
  • ✓Arbitrary nested member & index assignments (grid[y][x] = "#";, enemies[i].hp -= 10;)
  • ✓Recursive multi-file CLI imports & top-level circular import detection
  • ✓Class definition class Name ... end with C#-style constructor & default parameterless constructor
  • ✓Instance reference (this) & encapsulation access modifiers (public, private)
  • •Single inheritance class Sub extends Super ... end with super(...)
  • •Static class members (static ivar, static function)
  • •Class method interception (hook ClassName.method(args) then ... end)
  • •Namespaces integration & class scoping
  • •Native enumerations (enum State then IDLE, RUNNING, PAUSED end)
Next up: Single inheritance (class Sub extends Super ... end) and super(...) constructor chaining.
v1.0.8 Phase 8: Asynchronism, Modular Ecosystem & Web Planned
▾
  • •Non-blocking async routines (async / await) and lightweight coroutines (task / yield)
  • •StdE.Json — native parse & stringify of Tables to JSON
  • •StdE.Path — join, resolve, dirname, basename, extname
  • •StdE.Process — spawning child processes, command execution & pipes
  • •StdE.Term — ANSI colors/styles, terminal dimensions & cursor positioning
  • •Web package — HTTP client fetcher (Web.fetch) & server (Web.serve, Web.listen)
v1.0.9 Phase 9: Native 2D Game Engine (App), Tooling & Tour Planned
▾
  • •Native window creation with framerate & resolution control (App.window, App.fps)
  • •2D Canvas rendering (shapes, colors, sprites, text) with game loop hooks (App.onUpdate, App.onDraw)
  • •Real-time keyboard & mouse input (App.isKeyDown, App.mousePos)
  • •CLI developer tooling: krb fmt, krb test, --debug stepper & VS Code LSP
  • •Interactive Learning Manual ("Tour of Kuroba") with in-browser challenges
  • •Website & Docs Internationalization (i18n) with live language switcher (EN / FR / ES)
v2.0.0 Phase 10: Embedding SDK, Package Manager & Compiler Planned
▾
  • •Kuroba Embeddable Host SDK for C# (Unity), Godot, Node.js, and Browser apps
  • •Bytecode Virtual Machine optimization pass for high-throughput execution
  • •Standalone executable builder (krb build game.krb --out game.exe)
  • •Official Package Manager (kpm, kuroba.json, krb publish, krb install)
Shipped Releases (v1.0.0 – v1.0.6)
v1.0.6 Phase 6: Exception Handling & Web Documentation Completed
▾
  • ✓Official Website, Documentation & in-browser AST Playground (main.krb + custom modules)
  • ✓Exception handling with throw and try / catch (ivar e) / finally / end
  • ✓Structured exception metadata tables (exName, exLines, exCode, exContext, exTime)
  • ✓Trapping native runtime failures into structured tables & catchable [RecursionError]
  • ✓Async Playground terminal with inline copy() / copyKey(), Stop button & non-blocking sleep()
v1.0.5 Phase 5: The Vital Standard Library & Namespaces Completed
▾
  • ✓Namespaces (Main, Package ~Module), symbol discovery & selective imports (alias ~)
  • ✓Std.Math (random, arithmetic, clamping, trig, constants PI, TAU, E)
  • ✓Std.Time (sleep, now, perf, clock, stopwatch)
  • ✓Std.String & raven string interpolation (~"Hello {name}", str[i])
  • ✓Std.IO synchronous file operations (fileCopy, filePaste, fileExists, fileKill)
v1.0.4 Phase 4: Functions, Metaprogramming & CLI Ergonomics Completed
▾
  • ✓Variable lifecycle & explicit scope destruction (kill variable;)
  • ✓First-class functions & anonymous lambdas (function ~) with closures
  • ✓Function interception hooks (hook target(...) then ... this(...) end)
  • ✓Interactive REPL shell (krb) & CLI arguments (args, Std.Sys.args)
v1.0.3 Phase 3: Data Structures & Collections Completed
▾
  • ✓Strict lexical block scoping & multi-line comments (~~{{ ... }})
  • ✓Generic List<T>, Stack<T> (LIFO) & Queue<T> (FIFO) with push/pop/peek/count
  • ✓Associative Table dictionaries with field typing & dynamic field retyping
  • ✓Unified collection iteration (for (ivar item in col) & for (ivar i, v in col))
v1.0.2 Phase 2: Iteration & Interactive Console Completed
▾
  • ✓paste / pasteLn, exit(cond), clear(cond)
  • ✓Compound operators (+=, -=, *=, /=, %=, ++, --)
  • ✓Loops: for, while, do-while with break; and skip;
  • ✓Blocking prompt copy(...) & raw single-keypress capture copyKey()
v1.0.1 Phase 1: Fundamental Operators & Types Completed
▾
  • ✓Atomic variable swap operator (a <-> b;)
  • ✓Distinct Int / Float types, NULL, and strict non-nullability (~(Type))
  • ✓Comparisons (<, >, <=, >=), modulo (%) & dynamic transtyping (v~Type = ...)
v1.0.0 Core Engine Foundation Completed
▾
  • ✓Recursive descent parser & arithmetic engine with ivar / iconst
  • ✓Feather comments (~~), booleans (TRUE/FALSE) & short-circuit logic (&&, ||, !)
  • ✓Conditionals (if / elif / else / end) & pattern matching (given / case ... case ~ then)
