ABOUT KUROBA

A readable language engine built from scratch.

Kuroba (literally "Black Feather", abbreviated KRB) is an interpreted programming language created by MrYamiTsu in vanilla JavaScript and Node.js. It started with one clear goal: build an expressive, understandable language runtime with zero external dependencies that lets you write scripts, CLI utilities, and interactive text games comfortably.

Zero Black Boxes

Kuroba ships with "dependencies": {} in package.json. Every single part of the interpreter — from raw keyboard capture (copyKey()) and string interpolation (~"...") to multi-file module discovery and the browser runtime bundle — is transparent, readable JavaScript.

Safety Without Ceremony

Infer variables rapidly with ivar, or lock critical invariants with strict non-nullability (~(Type)), runtime checks (is), constants (iconst), atomic swaps (<->), and structured exception tables (try / catch).

Built for Both CLI & Web

The same lexer, recursive-descent parser, and evaluator run natively in Node.js (krb / node index.js) and inside your browser via kuroba-web.js with an asynchronous virtual terminal supporting interactive prompts and multi-file projects.

Practical Metaprogramming

Native function hooks (hook fn(...) then ... this(...) end), first-class closures, and symbol-driven namespaces allow clean modularity and instrumentation without complicated boilerplate.

ENGINE PIPELINE

How Kuroba executes your code

Every .krb source file flows cleanly through a modular 3-stage pipeline in src/, backed by zero-dependency runtime natives in src/runtime/ and Kuroba-written standard library modules in lib/std/:

Stage 01

Modular Lexer

Tokenizes ~~ comments, interpolated strings (~"{expr}"), operators, types, and line/column metadata for diagnostics.

Stage 02

Recursive Descent AST Parser

Builds a clean AST covering expressions, control structures, typed collections, nested member assignments, namespaces, and hooks.

Stage 03

Scoped AST Evaluator

Executes lexical block frames, validates nullability and casts at runtime, resolves multi-file imports recursively, and traps errors cleanly.
