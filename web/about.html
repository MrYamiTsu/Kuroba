ABOUT KUROBA

A readable language engine built from scratch.

Kuroba (literally "Black Feather", abbreviated KRB) is an interpreted programming language created by MrYamiTsu featuring a high-performance standalone Native C Engine and a companion zero-dependency in-browser Web VM. It started with one clear goal: build an expressive, understandable language runtime with zero external dependencies that lets you write scripts, CLI utilities, and interactive text games comfortably.

Zero Black Boxes

Kuroba ships with zero external dependencies. Every single part of the interpreter — from raw keyboard capture (copyKey()) and string interpolation (~"...") to native collections and the browser runtime bundle — is transparent, robust, and readable.

Safety Without Ceremony

Infer variables rapidly with ivar, or lock critical invariants with strict non-nullability (~(Type)), runtime checks (is), constants (iconst), atomic swaps (<->), and structured exception tables (try / catch).

Built for Both Desktop & Web

Execute scripts at maximum speed using the standalone Native C Engine (kuroba.cmd / krb.cmd) on Windows, Linux, and macOS, or run directly inside your browser via kuroba-web.js with an interactive virtual terminal.

Practical Metaprogramming

Native function hooks (hook fn(...) then ... orig(...) end), first-class closures, and symbol-driven namespaces allow clean modularity and instrumentation without complicated boilerplate.

ENGINE PIPELINE

How Kuroba executes your code

Every .krb source file flows cleanly through a high-performance 3-stage pipeline in engine/src/, backed by zero-dependency native standard library extensions (stdlib_krb.c):

Stage 01

High-Speed Scanner

Scans ~~ comments, interpolated strings (~"{expr}"), operators, type tokens, and line/column metadata for diagnostics.

Stage 02

Single-Pass Bytecode Compiler

Compiles source tokens directly into compact, cache-friendly bytecode instructions, resolving scopes, local offsets, closures, and interfaces.

Stage 03

Stack-Based Virtual Machine

Executes bytecode instructions with extreme speed, call frames, strict runtime type checking, and native standard library dispatch.
