Write scripts, tools, and games with zero dependencies.

Kuroba is an interpreted language built from scratch in Node.js with no external packages or build steps. It combines readable then ... end blocks, object-oriented classes with C#-style constructors, optional type enforcement, atomic swaps, and native function hooks.

CORE ARCHITECTURE

Designed for clarity, built from scratch.

ARCHITECTURE

Zero Dependencies

No node_modules, no transpilers, and zero build steps. The lexer, parser, evaluator, and standard libraries run natively in Node.js and inside web browsers.

~~ Pure Node.js & browser runtime
pasteLn("Zero external dependencies!");
TYPE SAFETY

Gradual & Strict Types

Type inference for rapid prototyping (ivar), or enforce automatic coercion (ivar~Int) and strict non-nullable contracts (ivar~(String)) to prevent bugs.

ivar~Int count = "42";      ~~ Coerced
ivar~(String) user = "Yami"; ~~ Non-null
ERGONOMICS

Atomic Value Swap

Swap values between two variables, list elements, or table properties atomically in a single statement without declaring temporary variables.

ivar a = 1; ivar b = 2;
a <-> b;             ~~ a=2, b=1
list[i] <-> list[j]; ~~ In-place
OBJECT-ORIENTED

Classes & Accessors

C#-style constructors without new, property interceptors (get / set) with direct value binding, and strict visibility (protected, isolated, exclusive).

class Player then
  get hp then return value; end
  set hp(v) then
    value = Math.max(0, v);
  end
end
METAPROGRAMMING

Non-Invasive Hooks

Intercept any existing function or class method at runtime with hook and delegate through this(...) or orig(...). Built for logging, profiling, and game mods.

hook compute(ivar x) then
  pasteLn(~"Hooked: {x}");
  return this(x);
end
LANGUAGE CORE

Enums & Pattern Matching

Type-safe immutable enumerations with optional custom values, verified at runtime with the is operator and branched via concise given ... case statements.

enum Role then ADMIN, GUEST end
given role then
  case Role.ADMIN then
    pasteLn("Admin access");
end
GAMING & MATH

Deterministic PRNG

Decoupled from Std.Math, StdE.Random provides a 32-bit Mulberry32 pseudo-random engine with seed reproducibility, Fisher-Yates shuffle, and RFC4122 UUID generation.

import StdE ~(Random) alias ~;
Random.seed(42);
ivar roll = Random.int(1, 20);
PERSISTENCE & I/O

Synchronous I/O & JSON

Read terminal prompts (copy, copyKey), sleep with 0% CPU burn (Atomics.wait), and read/write files or JSON structures with zero async callback overhead.

import StdE ~(Json) alias ~;
Json.write("save.json", data);
ivar save = Json.read("save.json");
SYNTAX CHEAT SHEET

Expressive, readable, concise.

Category / Concept Kuroba Syntax Runtime Behavior & Semantics
Console Output paste(x); / pasteLn(x); Prints to stdout without a newline (paste) or with trailing newline (pasteLn). Supports template interpolation.
Console Input copy("Prompt: "); / copyKey(); Blocking interactive line input or instant single-character capture in terminal raw mode.
Variables & Constants ivar x = 10; / iconst MAX = 100; Type-inferred mutable variables and immutable constants with re-assignment rejection.
Gradual Coercion ivar~Int count = "42"; Enforces automatic type coercion on declaration and subsequent assignments.
Strict Non-Nullability ivar~(String) name = "Kenji"; Strict contract rejecting NULL assignments with immediate [TypeError] diagnostics.
Atomic Swap a <-> b; / list[i] <-> list[j]; In-place atomic value exchange across variables, lists, or table properties without temporary vars.
String Interpolation ~"Score: {pts}/{max}" Evaluates embedded Kuroba expressions directly inside strings using the ~ prefix.
Pattern Matching given x then case 1 then ... break; case ~ then ... end Value branching with explicit fallthrough control (break;) and default fallback branch (case ~).
Iteration & Loops for (item in list) then ... end / do ... while Collection traversal with skip (continue) and break;, plus pre/post-test conditional loops.
Exception Safety try ... catch (ivar e) then ... finally ... end Structured exception safety trapping all 8 error classes with metadata tables (eName, eContext).
Memory Lifecycle kill variable; Destroys variable bindings from the active scope and releases references from memory.
Classes & Constructors class Player then function Player(...) then ... end end C#-style constructors without new keyword; automatic default constructor if omitted.
Custom Accessors get hp then return value; end / set hp(v) then ... end Property interceptors with raw storage access via value, avoiding recursive loops.
Encapsulation Guards public, protected, private, isolated, exclusive Granular access modifiers with private name mangling across inheritance hierarchies.
Inheritance & Base class Child from Parent then function Child() then base(); end end Single class inheritance with from and superclass delegation via base(...).
Type Verification obj is Player / val is Int Runtime type checking operator verifying primitives, collections, custom classes, and enums.
Native Enums enum Status then ACTIVE, IDLE end Named immutable enumerations with optional custom explicit values (e.g. OK = 200).
Function & Method Hooks hook target(x) then return this(x); end / orig(...) Non-invasive runtime interception for standalone functions (this) and class methods (orig).
Typed Collections List<T>, Stack<T>, Queue<T>, Table Built-in collections with .push(), .pop(), .peek(), .count(), and bracket/dot access.
Filesystem (Std.IO) IO.fileCopy() / IO.filePaste() / IO.fileKill() Synchronous file reading, writing, appending, existence checks, and deletion.
Deterministic PRNG (StdE.Random) Random.seed(42); / Random.int(1, 20); / Random.shuffle(d); Mulberry32 PRNG with seed reproducibility, Fisher-Yates shuffle, and RFC4122 UUIDs.
JSON Storage (StdE.Json) Json.stringify() / Json.parse() / Json.read() / Json.write() Seamless bidirectional translation between Kuroba Tables/Lists and JSON data.
