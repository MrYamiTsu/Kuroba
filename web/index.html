Write scripts, tools, and games with zero dependencies.

Kuroba is an interpreted language built from scratch in Node.js with no external packages or build step. It combines readable then ... end blocks, optional type enforcement, atomic variable swaps, and built-in function hooks.

CORE DESIGN

Practical features, clear syntax.

1. Zero External Dependencies

No node_modules, no transpilers, and no build tools. The lexer, parser, evaluator, and standard library live in plain JavaScript files you can read directly.

package.json:
"dependencies": {} ~~ 0 packages

2. Hybrid Typing & Non-Nullability

Skip type annotations while prototyping (ivar x = 10;), or enforce coercion (ivar~Int n = "42";) and non-null contracts (ivar~(String) u = "...";) when values need guarantees.

ivar~Int count = "50";    ~~ Coerced to Int 50
ivar~(String) id = NULL;  ~~ [TypeError] Rejected

3. Native Variable Swap (<->)

Swap two variables in place without declaring a temporary variable. Type compatibility and iconst immutability are verified automatically at runtime.

ivar a = 1; ivar b = 2;
a <-> b; ~~ a is now 2, b is now 1

4. Synchronous I/O

Read terminal lines (copy), capture single keypresses (copyKey), and read or write files (Std.IO) synchronously—ideal for CLI tools and terminal games without async boilerplate.

IO.filePaste("save.dat", data);
ivar content = IO.fileCopy("save.dat");

5. Function Hooks

Intercept any existing function with hook and call the original implementation via this(...). Built for logging, runtime patching, or game modifiers without altering source functions.

hook compute(ivar x) then
    pasteLn("Compute called with: " + x);
    return this(x);
end

6. Symbol-Based Modules

Organize code with namespace Pkg ~Module blocks independent of physical file names. Import full packages or expose specific modules directly into scope with alias ~.

import Std ~(Math, Time, String, IO) alias ~;
namespace Main then ... end
SYNTAX AT A GLANCE

Core Syntax

Category Kuroba Syntax Behavior
Console Output paste(x); / pasteLn(x); Prints to stdout without a newline (paste) or with a trailing newline (pasteLn).
Console Input copy("Prompt: "); / copyKey(); Blocking line input or instant single-character keypress capture in raw terminal mode.
Variables & Constants ivar x = 10; / iconst MAX = 100; Type-inferred variables (with multi-var propagation) and read-only constants.
String Interpolation ~"Score: {x}/{max}" Evaluates embedded Kuroba expressions directly inside strings using the ~ prefix.
Pattern Matching given x then case 1 then ... break; case ~ then ... end Value-based branching with explicit break; and a default fallback branch (case ~ then).
Typed Collections List<T>, Stack<T>, Queue<T>, Table Built-in collections with .push(), .pop(), .peek(), .count(), and dot-access fields.
Memory Lifecycle kill variable; Removes a variable from memory and its active lexical scope.
Disk Persistence IO.fileCopy(), IO.filePaste() Synchronous file read, write, append, existence check, and deletion via Std.IO.
