Deterministic, Expressive & Self-Contained.

Kuroba is an interpreted programming language built from scratch in vanilla Node.js with zero third-party dependencies. Powered by a strict recursive-descent AST interpreter, hybrid type inference with explicit coercion, and atomic variable swapping, Kuroba delivers full predictability without runtime bloat.

ARCHITECTURE & PRINCIPLES

Engineered for clarity, speed, and determinism.

1. Zero External Dependencies

No Babel, no TypeScript runtime, and no sprawling node_modules. The entire pipeline (Lexer, Parser, AST Evaluator, Scope Machine, and Standard Library) is contained within the repository. The complete codebase can be audited in a single sitting.

package.json:
"dependencies": {} ~~ Exactly 0 packages

2. Hybrid Typing & Strict Non-Nullability

Natural type inference by default (ivar x = 10;), instant explicit coercion (ivar~Int n = "42";), and strict non-nullability contracts (ivar~(String) u = "...";) that categorically reject NULL at runtime.

ivar~Int count = "50";    ~~ Coerced to Int 50
ivar~(String) id = NULL;  ~~ [TypeError] Rejected

3. Native Atomic Swap (<->)

Eliminates temporary variables. Kuroba validates type compatibility, guards immutable constants, and performs an atomic in-memory variable permutation in a single operation.

ivar a = 1; ivar b = 2;
a <-> b; ~~ a is now 2, b is now 1

4. Synchronous, Predictable I/O

Console I/O and disk persistence (Std.IO) without asynchronous promise clutter or event loop stalls. Features blocking line input (copy), raw single-key capture (copyKey), and direct file read/write operations.

IO.filePaste("save.dat", data);
ivar content = IO.fileCopy("save.dat");

5. Native Function Interception (Hooks)

Lexical monkey-patching that preserves the caller interface. Intercept any target function to inject logging, caching, or data validation with transparent delegation via this(...).

hook compute(ivar x) then
    pasteLn("Compute called with: " + x);
    return this(x);
end

6. Pure Symbol-Based Discovery

Physical file names on disk are irrelevant. Kuroba indexes module libraries strictly by their declared AST symbols (namespace Pkg ~Module then), ensuring modular reusability without path coupling.

import Std ~(Math, Time, String, IO) alias ~;
namespace Main then ... end
SYNTAX AT A GLANCE

Clean grammar without noise.

Category Kuroba Syntax Behavior
Console Output paste(x); / pasteLn(x); Direct stdout print without newline (paste) or with trailing newline (pasteLn).
Console Input copy("Prompt: "); / copyKey(); Synchronous blocking line input or instant raw single-character keypress capture.
Variables & Constants ivar x = 10; / iconst MAX = 100; Type-inferred variables and read-only constants protected against reassignment.
String Interpolation ~"Score: {x}/{max}" Evaluates embedded Kuroba expressions directly inside the string via raven tilde (~).
Pattern Matching given x then case: 1 ... break; case: ~ end Value-based pattern matching with a raven tilde fallback branch (case: ~).
Typed Collections List<T>, Stack<T>, Queue<T>, Table Heap data structures with native methods (.push(), .pop(), .count()).
Memory Lifecycle kill variable; Explicit variable destruction from memory and active lexical scope.
Disk Persistence IO.fileCopy(), IO.filePaste() Synchronous filesystem read, write, append, existence, and deletion via Std.IO.
