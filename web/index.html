Zero Dependencies Native C & Web OOP & Functional

Write scripts, tools, and games with zero dependencies.

Kuroba is an interpreted language powered by a high-performance Native C99 Bytecode Engine on desktop/CLI and an in-browser WebAssembly Runtime. It combines readable then ... end blocks, object-oriented classes with operator overloading, optional type enforcement, atomic swaps, and native function hooks.

ARCHITECTURE

Native C99 & WebAssembly

A self-contained native C bytecode engine (engine/kuroba.exe) for raw speed on desktop/CLI, compiled directly to WebAssembly in the browser. Zero node_modules.

~~ Run directly with native C binary
./kuroba main.krb
TYPE SAFETY

Gradual & Strict Types

Type inference for rapid prototyping (ivar), automatic coercion (ivar~Int), first-class function contracts (ivar~Function), and strict non-nullability (ivar~(String)).

ivar~Int count = "42";      ~~ Coerced
ivar~(String) user = "Yami"; ~~ Non-null
ERGONOMICS

Atomic Value Swap

Swap values between two variables, list elements, or table properties atomically in a single statement without declaring temporary variables.

ivar a = 1; ivar b = 2;
a <-> b;             ~~ a=2, b=1
list[i] <-> list[j]; ~~ In-place
OBJECT-ORIENTED

Classes & Operators

C#-style constructors without new, toString(), operator overloading (operator +), property accessors (get / set), and 5 visibility levels.

class Vec2 then
  public ivar~Float x = 0;
  operator +(ivar o) then return Vec2(this.x + o.x); end
end
METAPROGRAMMING

Non-Invasive Hooks

Intercept any unlocked function or class method at runtime with hook and delegate through orig(...), or guard critical APIs with iconst / isealed.

hook compute(ivar x) then
  pasteLn(~"Hooked: {x}");
  return orig(x);
end
LANGUAGE CORE

Enums & Pattern Matching

Type-safe immutable enumerations with optional custom values, verified at runtime with the is operator and branched via concise given ... case statements.

enum Role then ADMIN, GUEST end
given role then
  case Role.ADMIN then
    pasteLn("Admin access");
    break;
  end
end
GAMING & MATH

Deterministic PRNG

Decoupled from Std.Math, StdE.Random provides a 32-bit Mulberry32 pseudo-random engine with seed reproducibility, Fisher-Yates shuffle, and RFC4122 UUID generation.

import StdE ~(Random) alias ~;
Random.seed(42);
ivar roll = Random.int(1, 20);
PERSISTENCE & I/O

Synchronous I/O & JSON

Read terminal prompts (copy, copyKey), sleep with 0% CPU burn, and read/write files or JSON structures with zero async callback overhead.

import StdE ~(Json) alias ~;
Json.write("save.json", data);
ivar save = Json.read("save.json");
