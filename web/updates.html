v1.1.0 Native C Engine Architecture, Typed Parameters & Interactive Console I/O LATEST RELEASE
November 2026 ▾
★ Native C Engine isealed & unlock/lock Emoji Identifiers Typed Parameters Interactive copy() / copyKey() 187/187 Crash Tests Instant Startup

Kuroba v1.1.0 represents a monumental milestone in the language's evolution: the entire compiler, bytecode generator, and virtual machine have been re-engineered from the ground up as a blazing-fast, standalone Native C Engine (kuroba.exe / engine/). This release completely eliminates Node.js runtime overhead for desktop and CLI execution, achieving instant startup, zero background dependencies, and native binary efficiency while preserving full parity with the Web VM.

Along with native performance, v1.1.0 introduces gradual type annotations on function parameters (ivar~Type param), strict non-nullable parameter contracts (ivar~(String) strict), native interactive keyboard inputs (copy() and copyKey()), postfix operators (++, --), sealed variables (isealed) with one-shot unlock mechanics (unlock / lock with auto-resealing), first-class UTF-8 and Emoji identifier support (🚀, 🔥, 👑), and an extensive 187-test crash torture suite.

Native C Compiler & Bytecode VM

Self-contained native executable (engine/kuroba.exe) written in pure C99 with manual memory management, custom arena allocation, and compact bytecode instruction dispatch.

Sealed Variables (isealed) & Unlock / Lock

Protected variables declared with isealed rejecting reassignment until explicitly unlocked with unlock var;, which automatically re-seals upon mutation, or can be re-locked with lock var;.

Emoji & Unicode Identifiers

Full UTF-8 multi-byte support in identifiers allowing emojis (🚀, 🔥, 👑) and international characters across variables, constants, parameters, and functions.

Typed Function & Method Parameters

Annotate function and method signatures with explicit coercion types (ivar~Int x, ivar~Stack<Int> s) or enforce strict non-nullable constraints (ivar~(String) name) verified at call time.

Interactive Console Input Primitives

First-class global native functions copy(prompt) for reading full terminal lines and copyKey(prompt) for capturing raw single keystrokes without external libraries.

187/187 Conformance Torture Suite

Comprehensive torture suite in main.krb validating deep recursion, 10-level nested tables, PRNG determinism, metaprogramming hooks, 2D matrix swaps, sealed variables, and hot-loop exception trapping.

v1.0.8 OOP Finalization, Interface Contracts & Modular StdE COMPLETED
November 2026 ▾
★ Interfaces (as) Extended Visibility Property Accessors (get/set) StdE.Path StdE.Term StdE.Process StdE.Random StdE.Json

Kuroba v1.0.8 completes the Object-Oriented Architecture phase and delivers the full Standard Extended (StdE) suite. This release introduces pure interface contracts with the expressive as syntax, extended encapsulation modifiers (protected, isolated, exclusive), declarative get / set property interceptors with backing storage binding, and a robust platform library available in both Node.js and the Web.

Pure Interface Contracts (interface & as)
Define structural contracts without implementation. Classes implement interfaces via class Sub from Super as Inter1, Inter2 then ... end with strict ordering enforcement (from must precede as). Interfaces are non-callable and non-accessible directly, with full polymorphic runtime validation via is across class and interface hierarchies.
Extended Encapsulation Modifiers
Granular control over class member access: protected (accessible across subclasses, hidden from external callers), isolated (strictly exclusive and private to declaring class, completely uninherited), and exclusive (public on declaring class, absent from subclasses).
Declarative Property Accessors (get / set)
Seamless getter and setter property interceptors with raw backing storage access via the special value binding, preventing infinite recursion. Permissive layering allows defining single getters or setters, with strict iconst immutability enforcement.
Extended Standard Library (StdE)
Rich modular platform library: StdE.Path (cross-platform path resolution, normalization, and joining), StdE.Term (ANSI colors, terminal styling, cursor movement, and screen clearing), StdE.Process (synchronous execution, arguments, env variables, and system introspection), StdE.Random (stochastic engine with seeding, shuffling, UUIDs, tokens), and StdE.Json (bidirectional JSON parse/stringify).
Example: Interfaces, Encapsulation & Custom Accessors
~~ Pure interface contract
interface IMammal then
    function breathe();
    get warmBlooded;
end

interface ICanine from IMammal then
    function bark();
end

~~ Implement with inheritance and interface contracts
class Dog as ICanine then
    iconst warmBlooded = TRUE;
    private ivar _energy = 100;

    get energy then
        return this._energy;
    end

    function breathe() then
        return "inhale / exhale";
    end

    function bark() then
        return "Woof!";
    end
end

ivar d = Dog();
pasteLn(d.bark());           ~~ "Woof!"
pasteLn(d is ICanine);       ~~ TRUE
pasteLn(d is IMammal);       ~~ TRUE
v1.0.7 Object-Oriented Programming, Encapsulation & Language Ergonomics COMPLETED
November 2026 ▾
★ Classes & OOP C#-Style Constructors Inheritance (from) base(...) Chaining shared Members hook & orig public / private is Operator Native Enumerations (enum) Multi-Var Declarations Default Params Nested Member Assignments Browser CWD Guard

A landmark release introducing Kuroba's declarative Object-Oriented model layered cleanly on top of structured Tables. Developers gain first-class classes without verbose boilerplate: direct C#-style constructors without a new keyword, field encapsulation, method binding via this, and runtime type verification with is.

  • ✓ Class Declarations: class Name then ... end with public and private fields.
  • ✓ C#-Style Constructors: Function matching class name invoked directly (e.g. ivar hero = Hero("Kenji", 100);).
  • ✓ Parameterless Default Constructor: Automatic zero-argument constructor fallback when no custom constructor is declared.
  • ✓ Member Encapsulation: private ivar fields restricted to the class's own methods; external reads/writes throw [TypeError].
  • ✓ Instance Reference this: Dynamic binding for field/method access with root immutability guard.
  • ✓ Single Inheritance (from): Subtyping hierarchy class Child from Parent then ... end with recursive ancestor propagation.
  • ✓ Base Delegation (base): Explicit constructor chaining base(args...) and parent method delegation base.method(...).
  • ✓ Shared Static Members (shared): Grouped shared then ... end blocks and inline declarations with strict modifier ordering (shared private).
  • ✓ Namespace Class Modules & Qualified Paths: Declare classes directly as namespace modules via namespace Name ~class ClassName [from SuperClass] then ... end. Fully integrated with multi-file imports (Entities.Player()), qualified inheritance (class Warrior from Entities.Player), instance checks (w is Entities.Player), and type annotations (ivar ~Entities.Player p).
  • ✓ Native Enumerations (enum): Fixed sets of immutable named constants with default string identity (State.IDLE), custom values (OK = 200), duplicate detection, and instant is operator runtime type verification.
  • ✓ Unified Error Tables (eName, eContext): Standardized error table structure across the entire engine and runtime. All internal diagnostic errors now emit structured objects with eName, eContext, eLine, and eCol for seamless try / catch inspection.
  • ✓ Class Method Interception: hook ClassName.method with orig(...) delegation, leaving this bound to the instance, and unhookable private methods.
  • ✓ Type Operator is: Full runtime verification across primitives, nullable types, collections, and polymorphic inheritance hierarchies (hero is Player, hero is Entity, hero is Table).
  • ✓ Trailing Multi-Var Propagation: ivar a, b = 1, 2; and ivar c, d = 4; (both receive 4).
  • ✓ Default Parameter Values: function f(ivar a, ivar b = 10) evaluated fresh per call.
  • ✓ Deep Nested Assignments: Arbitrarily nested assignment paths supported (game.players[0].inventory[1].qty += 5;).
  • ✓ Recursive Module Imports: Multi-file CLI imports with circular dependency cycle guards.
  • ✓ Browser Engine Guard: Rebundled kuroba-web.js with safe browser environment detection. 
class Character then
    public ivar name = "Warrior";
    private ivar _energy = 100;

    function Character(ivar name, ivar energy) then
        this.name = name;
        this._energy = energy;
    end

    function useSkill(ivar cost) then
        if (this._energy < cost) then
            pasteLn(~"[{this.name}] Not enough energy!");
            return FALSE;
        end
        this._energy -= cost;
        pasteLn(~"[{this.name}] Cast skill! Energy left: {this._energy}");
        return TRUE;
    end
end

ivar hero = Character("Kenji", 80);
hero.useSkill(25);
pasteLn(hero is Character); ~~ TRUE
pasteLn(hero is Table);     ~~ TRUE

try / catch / finally throw 512 Recursion Guard Unified given / case Web IDE & Playground

Introduced mission-critical resilience with structured exception handling, a 512-frame call stack guard against runaway infinite loops, unified pattern matching semantics, and the official interactive in-browser playground.

  • ✓ Structured Exception Handling: try, catch (ivar err), finally, and end block scoping.
  • ✓ Rich Exception Tables: throw emits tables with eName, eCode, eContext, eTime, and eLines.
  • ✓ Infinite Recursion Guard: Hard limit of 512 recursive call frames throwing descriptive [RecursionError].
  • ✓ Unified Pattern Matching: given statement supporting both case <val> then and fallback case ~ then.
  • ✓ Official Web IDE: Multi-file tabs, virtual terminal, smart auto-indentation, and URL code sharing. 
import Std ~(Time) alias ~;

ivar balance = 50;
ivar amount = 120;

try
    if (balance < amount) then
        throw {
            eName: "InsufficientFunds",
            eCode: 402,
            eContext: "Checkout",
            eTime: Time.now()
        };
    end
catch (ivar err) then
    pasteLn(~"Caught error: {err.eName} (Code {err.eCode})");
finally
    pasteLn("Audit complete.");
end
