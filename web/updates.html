v1.0.7 Object-Oriented Programming, Encapsulation & Language Ergonomics LATEST RELEASE
November 2026 ▾
★ Classes & OOP C#-Style Constructors public / private is Operator Multi-Var Declarations Default Params Nested Member Assignments Browser CWD Guard

A landmark release introducing Kuroba's declarative Object-Oriented model layered cleanly on top of structured Tables. Developers gain first-class classes without verbose boilerplate: direct C#-style constructors without a new keyword, field encapsulation, method binding via this, and runtime type verification with is.

  • ✓ Class Declarations: class Name then ... end with public and private fields.
  • ✓ C#-Style Constructors: Function matching class name invoked directly (e.g. ivar hero = Hero("Kenji", 100);).
  • ✓ Parameterless Default Constructor: Automatic zero-argument constructor fallback when no custom constructor is declared.
  • ✓ Member Encapsulation: private ivar fields restricted to the class's own methods; external reads/writes throw [TypeError].
  • ✓ Instance Reference this: Dynamic binding for field/method access with root immutability guard.
  • ✓ Type Operator is: Full runtime verification across primitives, nullable types, collections, and classes (hero is Hero, hero is Table).
  • ✓ Trailing Multi-Var Propagation: ivar a, b = 1, 2; and ivar c, d = 4; (both receive 4).
  • ✓ Default Parameter Values: function f(ivar a, ivar b = 10) evaluated fresh per call.
  • ✓ Deep Nested Assignments: Arbitrarily nested assignment paths supported (game.players[0].inventory[1].qty += 5;).
  • ✓ Recursive Module Imports: Multi-file CLI imports with circular dependency cycle guards.
  • ✓ Browser Engine Guard: Rebundled kuroba-web.js with safe browser environment detection. 
class Character then
    public ivar name = "Warrior";
    private ivar _energy = 100;

    function Character(ivar name, ivar energy) then
        this.name = name;
        this._energy = energy;
    end

    function useSkill(ivar cost) then
        if (this._energy < cost) then
            pasteLn(~"[{this.name}] Not enough energy!");
            return FALSE;
        end
        this._energy -= cost;
        pasteLn(~"[{this.name}] Cast skill! Energy left: {this._energy}");
        return TRUE;
    end
end

ivar hero = Character("Kenji", 80);
hero.useSkill(25);
pasteLn(hero is Character); ~~ TRUE
pasteLn(hero is Table);     ~~ TRUE
v1.0.6 Structured Exceptions, Recursion Guard & Web Playground SHIPPED
November 2026 ▾
try / catch / finally throw 512 Recursion Guard Unified given / case Web IDE & Playground

Introduced mission-critical resilience with structured exception handling, a 512-frame call stack guard against runaway infinite loops, unified pattern matching semantics, and the official interactive in-browser playground.

  • ✓ Structured Exception Handling: try, catch (ivar err), finally, and end block scoping.
  • ✓ Rich Exception Tables: throw emits tables with exName, exCode, exContext, exTime, and exLines.
  • ✓ Infinite Recursion Guard: Hard limit of 512 recursive call frames throwing descriptive [RecursionError].
  • ✓ Unified Pattern Matching: given statement supporting both case <val> then and fallback case ~ then.
  • ✓ Official Web IDE: Multi-file tabs, virtual terminal, smart auto-indentation, and URL code sharing. 
import Std ~(Time) alias ~;

ivar balance = 50;
ivar amount = 120;

try
    if (balance < amount) then
        throw {
            exName: "InsufficientFunds",
            exCode: 402,
            exContext: "Checkout",
            exTime: Time.now()
        };
    end
catch (ivar err) then
    pasteLn(~"Caught error: {err.exName} (Code {err.exCode})");
finally
    pasteLn("Audit complete.");
end
v1.0.5 Standard Library Modules, Namespaces & String Interpolation SHIPPED
November 2026 ▾
Std.Math Std.Time Std.String Std.IO namespace Main / Std String Interpolation ~"..." String Indexing

Standardized Kuroba's modular library ecosystem with four built-in modules, full string manipulation capabilities, string interpolation syntax, and symbol discovery.

  • ✓ Std.Math Module: Constants PI, TAU, E and functions random, sqrt, sin, clamp, dist, etc.
  • ✓ Std.Time Module: High-resolution timers, sleep(ms), timestamps, and clock benchmarks.
  • ✓ Std.String Module: Transformation primitives: split, join, trim, upper, lower, replace.
  • ✓ Std.IO Module: Synchronous file operations: fileCopy, filePaste, filePasteLn, fileExists, fileKill.
  • ✓ String Interpolation: ~"Value is {val + 1}" with expression evaluation inside curly braces.
  • ✓ String Subscripts & Count: Zero-indexed read access (str[i]) and str.count() method.
  • ✓ Modular Namespaces: namespace Std ~Module then ... end and import Std ~(Math) alias ~;. 
import Std ~(Math, Time) alias ~;

ivar roll = Math.random(1, 20);
ivar hero = "Kenji";
pasteLn(~"Adventurer {hero} rolled a {roll} on the D20!");
